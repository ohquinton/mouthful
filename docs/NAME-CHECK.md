# Name check: "Mouthful" (release-privacy, 2026-10-29)

Not legal advice. Blocks branding spend and public launch, not the beta.

## Findings

- **USPTO:** no live MOUTHFUL word mark in classes 9, 41 or 42. Closest: **BE MOUTHFUL** (reg. 6444251, class 41,
  online leadership program; same owner filed "BE MOUTHFUL. BE HEARD.", abandoned). MOUTHFUL (85799976) is
  live in class 43 (restaurants). Other live class 41 composites: MAKE EACH MOUTHFUL MATTER, BIG MOUTHFULS,
  MOUTHFUL OF GRAFFITI, THE MOUTHFUL PODCAST DDS. All class 9 marks are dead.
- **CIPO:** a mirror shows 0 Canadian MOUTHFUL marks. Confirm by hand. WIPO not checked.
- **App Store:** **Mouthful: Voice to To-Do List** (Foundry One Technology LLC, released 2026-03-15), genres
  Productivity **and Education**, a voice app whose description opens "Say it out loud. That is the whole app."
  Earlier US use, close field. Food apps named Mouthful are low risk. mouthful.app is a live AI calorie tracker.
- **Domains:** mouthful.app taken (calorie tracker); mouthful.com taken; getmouthful.com registered, no site;
  mouthful.ca parked (maybe for sale); mouthfulapp.com probably free.

## Risk

- **Canada: low to medium.** No register conflict found.
- **US: medium.** Foundry One's earlier common-law use for a voice app in Education, plus App Store confusion;
  BE MOUTHFUL could be cited against a class 41 application. A suffix doesn't help ("Speak It Out Loud" echoes
  their tagline).

## Filing in Canada ourselves

CIPO 2026 online fees: $491.06 first class + $149.04 each extra: **$640.10 for classes 9 + 41**, $789.14 with 42.
Search CIPO by hand → file online with Goods and Services Manual wording (e.g. class 9 "downloadable mobile
application for speech practice", class 41 "providing online training in public speaking") → examination about
1.5–3 years → office action → 2-month opposition → registration. Use isn't required before filing.
